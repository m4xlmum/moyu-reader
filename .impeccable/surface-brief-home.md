# 首页（起始页）

## Scope

`src/renderer/home.html` 与 `src/renderer/src/home/`。应用启动后的第一屏，也是所有「打开某个站点」动作的起点。窗口为 960×540 的 16:9 横屏，首页占据两条工具栏之间的正文区（约 960×458）。

## Visitor mode

**Operate。** 用户来这里是为了尽快开始读，不是为了被说服。界面的成功标准是他能一眼认出这是什么，并在两秒内打开想读的东西。

## Audience, job, action

- **受众**：办公室 Windows 用户，屏幕随时可能被看到（走过来的同事，或正在进行的屏幕共享）。
- **任务**：在不离开工作界面的前提下开始阅读。
- **动作**：打开某个站点、继续上次的阅读、搜索。
- **内容**：站点来自「我的站点」与内置热门站点（`src/shared/presets.ts`）；顺序遵循浏览器惯例——自己固定的 → 常访问的 → 预置的。历史与书签来自本地存储，取其中的图标复用。全部为真实数据，不虚构任何统计或评价。

## Constraints

- chrome 层覆盖整个窗口，正文区**必须可透明**：窗口透明时用户看到的是桌面，不是我们的背景色。
- **禁止毛玻璃**：`backdrop-filter` 在透明窗口背后模糊不了桌面，只能模糊自身内容。
- 正文区高度仅约 458px，且 16:9 下宽度充足、高度紧张——横向组织优先。
- 界面语言为简体中文。正文与关键标签不小于 12px。
- 透明度会常态处于 25%–45%，因此**关键控件的可辨识不能只靠颜色**，需要形状或位置上的区分。

## Chosen direction

**canon —— 品类标准做法，以完全的工艺水准执行。**

用户在方向决策页上选择了「品类标准做法」这个选项，而不是任何一套带有主张的视觉世界。按 impeccable 的规则，这一选择即承诺：**惯例就是承诺本身**，必须完整执行，不做反讽，也不夹带私货。

工艺基准由用户指定为：**Chrome / Edge 的新标签页**。也就是——中性的浅色底、克制的分隔线、单一强调色、大量留白、界面退到内容之后；站点磁贴用圆形图标加标签，没有图标时用首字占位；搜索框是居中的胶囊，获得焦点时以跟随形状的投影响应。

被放弃的方向：初版曾按发牌结果做过一套「机读答题卡」的世界（卡纸底、登记红、题号与椭圆、黑体/宋体分工）。用户选择 canon 后该方向**整体废弃**，不得以任何形式残留。

## Direction contract

**THESIS** — 这是一个浏览器起始页，不是一件作品。它拥有的一件东西是「无事发生」：页面不主张任何东西，用户的目光直接穿过它落到自己的站点上。它拒绝的是把起始页当成品牌舞台——放大标语、装饰性插图、入场动画、任何需要用户先解读一遍才能用的东西。

**OWN-WORLD** — 白底 `#ffffff`，文字 `#111827`，次级文字 `#5b6472`，分隔线 `#e5e7eb`，强调色 `#2563eb`。全部为中性灰阶加单一强调色，强调色只出现在焦点、当前项与主操作上。系统 UI 字族（Windows 上落为微软雅黑），固定级差而非流式。组件语汇：居中胶囊搜索框、圆形首字磁贴、圆角矩形按钮与输入框、一像素分隔线。把所有文字拿掉后，剩下的应该是任何浏览器都会画出来的那些形状。

**STORY** — 用户认出这是搜索与站点入口，扫一眼磁贴找到要读的站点，点开。全程不需要思考这个界面是什么。

**FIRST VIEWPORT** — 整屏是白色。正中偏上一条 760px 的窄栏：顶部是 30px 的标识，其下是 46px 高的胶囊搜索框（左侧 17px 线性放大镜），再下是「继续上次」的一行文字入口，再下是站点磁贴网格（84px 列宽、40px 圆形图标、12px 标签）居中排布。最下方一行 12px 脚注给出两个老板键。搜索框是第一动作，位于整屏水平正中。

**FORM** — 品类标准做法（canon）。用户在方向决策页上主动选择了它，工艺基准指定为 Chrome / Edge 新标签页。发牌键 `784114e2`。没有 QUALITY BAR 卡片：canon 的基准是真实产品而非卡片。

**FINISH** — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
